## ✨ O que é este projeto?

O **Guia do Hóspede Digital** é uma aplicação web mobile-first que funciona como um concierge digital completo para pousadas, chalés e hospedagens boutique. O hóspede acessa via link ou QR code — sem baixar nenhum aplicativo — e encontra tudo o que precisa para aproveitar a estadia ao máximo.

## 🗂️ Seções do Guia

| Seção | Descrição |
|---|---|
| 🏠 **Boas-Vindas** | Slideshow imersivo com fotos da hospedagem e botão de acesso ao guia |
| 📶 **Wi-Fi** | Nome da rede e senha com cópia automática por toque |
| 🧭 **Como Chegar** | Rota passo a passo + botão de abertura no Google Maps / Waze |
| ☕ **Café da Manhã** | Cardápio completo da cesta, horário de entrega e restrições alimentares |
| 🍷 **Minibar** | Lista de itens disponíveis no chalé com preços |
| 🌿 **Spa & Lazer** | Ofurô, massagens e sauna — com agendamento via WhatsApp |
| 🔥 **Guia & Regras** | Instruções de lareira, horário de silêncio, check-in/out e cuidado ambiental |
| 🍽️ **Gastronomia** | Restaurantes recomendados com fotos e localização |
| 🗺️ **Passeios** | Trilhas e pontos turísticos com dificuldade, distância e dicas secretas |
| 💬 **Recepção 24h** | Acesso direto ao WhatsApp da pousada com um toque |

## 🎨 Destaques de Design

- **Visual premium** — Paleta areia e carvão com glassmorphism e animações suaves
- **Mobile-first** — Experiência nativa no celular, sem instalar nada
- **Apresentação Desktop** — Painel de apresentação ao lado do mockup de celular
- **Relógio ao vivo** — Horário, data e saudação personalizados em tempo real
- **Status bar realista** — Simula a interface de um iPhone moderno
- **Zero rolagem desnecessária** — Navegação fluida por abas e seções

## 🚀 Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/guia-de-boas-vindas.git

# Entre na pasta
cd guia-de-boas-vindas

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Acesse em `http://localhost:5173`
